### 画像の作り直し方

文字や価格を直したときは、`scripts/` のプログラムを順番に実行すると、`画像/` の中身が作り直されます。
正方形の画像の文字は `03_正方形.py` の中で変えられます。

```bash
cd 2027年度版/scripts
python3 01_表紙とバナー.py
python3 02_ポスター.py
python3 03_正方形.py
python3 04_送料無料バナー.py
python3 05_選び方ガイド.py
python3 06_中身の紹介.py
python3 07_カレンダー.py
python3 08_カレンダーバナー.py
```

必要なもの：Python 3、Pillow、NumPy、pdftoppm（poppler-utils）、Noto Serif CJK フォント（`fonts-noto-cjk`）
